# Moodify
Spotify Player Based on Your Mood

> [!NOTE]
> I have used uv package manager for this project. You can use any package manager of your liking.


# Python Libraries Used
- OpenCV2
- DeepFace
- NumPy
- Tkinter
- Webbrowser
- Pillow

## Install Dependencies
'''
uv pip freeze --python .venv/bin/python > requirements.txt
'''
